HOW IT WORKS
══════════════════════════════════════════════════════════════════════════════

STEP 1: User Goes to Forgot Password Page
   ↓
   Frontend: http://localhost:3000/forgot-password
   (or production: https://szeconnect.onrender.com/forgot-password)

STEP 2: User Enters Email Address
   ↓
   ForgotPasswordPage.jsx displays email input form

STEP 3: User Clicks "Send Email" Button
   ↓
   Frontend validates:
   ├─ Email format (regex validation)
   └─ Email is not empty

STEP 4: Frontend Sends to Backend
   ↓
   POST http://localhost:4000/forgot-password
   Content-Type: application/json
   Body: {"email":"adamk@example.com"}

STEP 5: Backend Receives Request
   ↓
   handleForgotPassword() processes:
   ├─ Validates email is provided
   ├─ Normalizes email to lowercase
   └─ Checks if email in database

STEP 6: Email Validation
   ↓
   Query: SELECT FROM users WHERE LOWER(email) = 'adamk@example.com'
   
   If NOT found:
   └─ Return 200 OK (security - don't reveal if email exists)
      Message: "If the email exists..."
   
   If FOUND:
   └─ Continue to step 7

STEP 7: Generate Temporary Password
   ↓
   tempPassword = crypto.randomBytes(6).toString('hex')
   Example output: "a1b2c3d4e5f6"

STEP 8: Hash Password with Bcrypt
   ↓
   hashedPassword = await bcrypt.hash(tempPassword, 12)
   Rounds: 12 (same as registration)

STEP 9: Update Database
   ↓
   UPDATE users 
   SET password_hash = hashedPassword
   WHERE user_id = 123

STEP 10: Send Email
   ↓
   sendForgotPasswordEmail(user, tempPassword)
   ├─ Creates HTML email
   ├─ Shows password prominently (28px)
   ├─ Includes instructions
   ├─ Sends via Gmail SMTP
   └─ Returns success

STEP 11: Return Response to Frontend
   ↓
   Success Response:
   {
     "success": true,
     "message": "Temporary password has been sent to your email..."
   }

STEP 12: Frontend Shows Success Message
   ↓
   ForgotPasswordPage displays:
   ├─ Green success message
   ├─ Auto-redirects to /login after 3 seconds
   └─ User can click back to login manually

STEP 13: User Receives Email
   ↓
   Email arrives with:
   ├─ Their username
   ├─ Large temporary password display
   ├─ Instructions (4 steps)
   ├─ Security warning
   └─ Support info

STEP 14: User Logs In
   ↓
   Goes to http://localhost:3000/login
   ├─ Email: adamk@example.com
   ├─ Password: a1b2c3d4e5f6 (from email)
   └─ Clicks Login

STEP 15: User Changes Password
   ↓
   Goes to Profile page
   ├─ Click "Change Password"
   ├─ Enters new permanent password
   ├─ Confirms password
   └─ Saves (updates password_hash again)
